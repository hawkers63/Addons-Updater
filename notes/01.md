# ESO Addons Updater 1.0

Double-click **Run-Addons-Updater.bat** in **C:\Addons.Updater**. It uses Python 3.11 and CustomTkinter, which are already installed on this PC. The app opens a read-only inventory of **F:\Documents\Elder Scrolls Online\live\Addons**.

## Find and apply updates

1. Click **Check GitHub releases** to check linked publisher repositories for stable releases. CharacterMarkdown has a verified built-in source. For another add-on, select it, enter its publisher’s public GitHub repository and click **Save**. The app saves that mapping locally in **release_sources.json**.
2. For a release with an attached ZIP, click **Preview release ZIP**. For an ESOUI or other publisher download, get the ZIP in your browser, then click **Import ZIP…**. The preview shows each add-on folder, the package version and the version it would replace. When versions use different formats, compare them using the publisher’s release notes. GitHub’s release tag and the version declared inside a ZIP can differ.
3. Close ESO and other add-on managers. Select the folders you want to change and click **Back up and apply**. The app keeps the original folders under **C:\Addons.Updater\Backups** and replaces the selected folders as complete units. This also clears files left behind by older releases of the same package. Vortex-deployed folders are blocked from installation here. Update those through Vortex.

For bulk updates of add-ons hosted only on ESOUI, use **Open Minion site**. Minion is ESOUI’s supported add-on manager. MMOUI’s terms prohibit scripted access, so this app uses user-opened ESOUI listings and local ZIP imports for that catalog. [Minion](https://www.minion.gg/) · [MMOUI terms](https://mmoui.com/?tos=)

## Review old add-ons

Use the **Review** filter for discontinued listings, conflicting manifests and older API declarations. The app shows which installed add-ons require the selected folder and identifies numeric minimum-version mismatches when available.

The initial scan found five removal candidates based on ESOUI’s **Discontinued & Outdated** listings. Review whether you still use them. MundusMap belongs to Vortex. [CritPercent](https://www.esoui.com/downloads/info951.html) · [ESO-Database Export](https://www.esoui.com/downloads/info916.html) · [ESO-Database Game Data Export](https://www.esoui.com/downloads/info2687.html) · [ESO-Database Leaderboard Export](https://www.esoui.com/downloads/info3438.html) · [MundusMap](https://www.esoui.com/downloads/info257.html)

To check API declarations against your game client, type **/script d(GetAPIVersion())** in ESO chat. Enter the returned number in **Live game API** and click **Apply**. Treat an older declaration as a compatibility check. ESOUI maintainers explain that add-ons can still work with older declarations. [ESOUI release guidance](https://www.esoui.com/forums/showpost.php?p=49229&postcount=1)

## Restore a folder

Close ESO and other add-on managers. Click **Backups** and open the appropriate dated operation folder. Its **operation.json** identifies the target and the folders changed. Move the current version of the relevant folder out of **AddOns**, then copy the saved original from the backup into **AddOns**. If the operation added a new folder, the operation record identifies it as an **Install** and there is no previous copy to restore. ESO stores **SavedVariables** separately beside **AddOns**.
